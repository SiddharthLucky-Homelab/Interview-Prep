# CAP Theorem

Summary
- In a network partition, choose between consistency or availability. Most distributed systems favor AP with compensations or tune for CP per use case.

Implications
- Align pattern choice (e.g., [[event-sourcing]], [[cqrs]]) with domain consistency needs.
